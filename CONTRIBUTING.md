# Contributing to RunRat

Thanks for considering a contribution.

## Before You Start

- Open an issue first for major changes so the direction is clear
- Keep pull requests focused and small when possible
- Be explicit about any behavior changes in the PR description

## Local Setup

```bash
swift build
swift run
```

To create an app bundle locally:

```bash
./scripts/make-app.sh
```

## Style

- Follow the existing Swift style in the repository
- Prefer small, readable types and functions
- Keep comments brief and only where they add clarity

## Pull Requests

- Describe what changed and why
- Mention how you validated the change locally
- Include screenshots or short recordings for visible UI changes when helpful

## Issues

Bug reports are most useful when they include:

- macOS version
- Swift or Xcode version
- Steps to reproduce
- What you expected
- What actually happened
